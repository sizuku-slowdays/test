からだパワー UI v2

使い方
1. ZIPを解凍
2. index.html をダブルクリック
3. Chromeなどで開く

v2で追加・変更
・「筋肉マッチョ」→「マッチョ」
・カテゴリを絵文字＋子ども向け表現に変更
・食材名に読みを表示
・説明文の難しい語に読みを補助
・「主な栄養」をボタン化し、栄養ミニ図鑑を表示
・栄養から関連食材へ移動可能
・今日のパワーをポイント表示ではなくゲージ＋言葉に変更
・ゲージは栄養必要量の充足率ではなく、ゲーム上の目安と明記
・「もう少し集める？」の候補をタップ可能に変更

注意
現在の★とゲージはアプリ試作用のv1ルールです。
栄養学的な「必要量を満たした」判定ではありません。

次のv3候補
・食事履歴を日付ごとに保存
・姉妹別「おいしい／食べられる／料理による／苦手／イヤ」
・料理ごとの成功記録
・本人が食べられるものだけで追加候補を出す


v2.1 表記改修
・子ども向けUIを「漢字（ふりがな）」方式へ変更
・食材名の読みを漢字の直後に表示
・説明文の漢字にも読み補助を追加
・説明文の句読点を整理
・「ハンバーグでも、筋肉（きんにく）マッチョ！」のように自然な読点を追加


v3
・基本UI語のルビを削減（今日食べたもの／入ってる栄養など）
・姉妹別の食材評価を保存
  😍 おいしい！
  🙂 食べられる
  🤔 料理による
  😣 苦手
  🚫 イヤ！
・「料理による」は食べられた料理名・調理法をメモ
・評価は「今日食べた」を取り消しても消えない
・追加候補は「苦手／イヤ」を避け、「おいしい／食べられる」を優先


v3.1 アレルギー対応
・食材詳細に「⚠️ アレルギー」を追加
・好き嫌い評価とは完全に別管理
・子ども別に保存
・アレルギー登録食材は「もう少し集める？」候補から完全除外
・食材カードにも警告表示
・長女のナッツアレルギーを初期設定（マスター内の該当ナッツ食材がある場合）
※ 今後のレシピ機能でも、アレルギー食材を材料に含むレシピは候補から除外する設計。


v4 PWA / スマホ確認版
・スマホ向けレイアウト強化
・下部ナビを固定し、アプリ風に操作しやすく調整
・PWA manifest追加
・ホーム画面追加に対応（HTTPS配信時）
・Service Worker追加（HTTPS配信時はオフライン表示に対応）
・アイコン追加
・「まずは、今日食べたものを選ぼう！」はルビなし
・「まだないよ。ずかんからえらんでね。」の句点修正

※ ZIPをスマホに送って直接開くだけではPWAインストールはできません。
   GitHub Pages / Cloudflare Pages / cetus.fun などHTTPSで公開すると、
   iPhone/Androidのブラウザからホーム画面に追加してアプリ風に使えます。


v5 まとめて入力版
・食べもの図鑑に「☑️ まとめて選ぶ」を追加
・複数の食材を一気に選択して「今日食べたものに追加」できる
・選択中の食材はチェック表示
・すでに今日食べたものは、まとめて選ぶ開始時に選択済みになる
・個別の食材詳細画面も従来どおり使用可能
・「今日食べたもの」「入ってる栄養」など基本UI語はルビなし方針
